# Linguablocks

A native Nintendo DSi / DS homebrew game for two players revising Spanish and
French. Questions earn XP and *game time*; the game time buys a round of Tetris
or Chess. Everything it needs is in this folder -- no external assets, no image
or audio files, just C.

* **Spanish** content is the complete Pearson Edexcel GCSE Spanish (2024)
  Foundation + Higher vocabulary list: greetings, numbers, dates, time,
  colours, cultural words, phrases, grammar words, adjectives, nouns and verbs.
* **French** content is the AQA GCSE French *Education and work* vocabulary
  booklet: types of education, uniform, subjects, activities, facilities,
  opinions, success, problems, work and jobs.

The imported lists hold **1,650 Spanish** and **413 French** entries. Rows from
conjugation tables are not copied into the flashcard pool -- every verb form is
generated by `conjugate.c` -- but the infinitives themselves are included. The
28 gap-fill sentences and the 60 drill verbs stay hand-written so the answers
match the grammar engine.

## Features

| Area | What it does |
| --- | --- |
| Main menu | Play Spanish, Play French, Setup Drills, Play Tetris, Play Chess. |
| Flashcard mode | English prompt, four target-language options. |
| Fill the gap | Tap the word that completes the sentence. |
| Tense drill | Conjugate a verb in the present / preterite (passé composé) / imperfect / future. |
| Ending drill | Choose the ending for a given verb, tense and person. |
| Drill setup | Four big touch toggles choose exactly which question types a session contains; the choice is saved. |
| 10 second timer | Strict countdown; at zero the answer counts as a miss, the buzzer plays and the rule is shown. |
| Explanations | Every wrong answer (and every timeout) explains the rule, e.g. *"regular -er verb. In the present tense drop the -er and add -e, -es, -e, -ons, -ez, -ent. For 'nous' the ending is -ons, so parler -> parlons."* |
| XP + game time | +XP and +1 second of game time per correct answer; wrong answers earn nothing. |
| Daily goal | 15 correct answers per session extends the streak and pays +30 s of game time. |
| Tetris | 10x20 board, 7-bag randomiser, wall kicks, lock delay, ghost piece, line scoring, levels. |
| Chess | Full legal-move chess (castling, en passant, four-way promotion) against a negamax AI; tap a piece, tap a gold square. |
| Save file | `sd:/langblocks.sav` (falls back to `fat:/`), written atomically via a temp file. |

## Building

Requires the latest devkitPro toolchain (devkitARM + libnds + libfat):

```sh
export DEVKITPRO=/opt/devkitpro
export DEVKITARM=$DEVKITPRO/devkitARM
export PATH=$DEVKITARM/bin:$DEVKITPRO/tools/bin:$PATH

cd langblocks
make            # produces langblocks.nds
make clean
```

`libfat` is linked by the `Makefile` (`LIBS := -lfat -lnds9`).

## Running it

Copy `langblocks.nds` to the SD card and launch it from the DSi menu
(TWiLight Menu++ / an SD-card launcher), or run it in any DS emulator
(no$GBA, melonDS, DeSmuME).

The save file is created at the filesystem root: `sd:/langblocks.sav` on a DSi,
`fat:/langblocks.sav` on a DS flashcard. A version 1 save from an older build is
ignored and replaced with a fresh profile.

## Controls

**Menus:** touch the entries, or D-pad + A. B goes back.

**Drill setup:** tap a card to switch a question type on or off (at least one
type always stays on), then START DRILLS. The selection is stored in the save
file.

**Quiz:** tap an answer on the bottom screen, or D-pad to move the highlight and
A to confirm. After feedback, tap anywhere (or A/B) to continue. B in a quiz
returns to the menu.

**Tetris:** touch buttons (ROTATE / DROP / LEFT / RIGHT / DOWN / PAUSE) with
auto-repeat, or D-pad to move, A to rotate, B to hard drop, START to pause,
SELECT to quit.

**Chess:** tap one of your (white) pieces, then tap a gold destination. When a
pawn reaches the last rank, a QUEEN / ROOK / BISHOP / KNIGHT picker appears.
The last move is outlined in blue. RESIGN ends the game, SELECT quits to the
menu.

## Design notes

* **No assets, no allocation.** Both screens are 16bpp bitmaps written by hand;
  the font is baked into `font5x7.h`; sounds are generated into static buffers.
  There is no `malloc` anywhere, which is the safest thing you can do on a DS.
* **One source of truth for grammar.** Verb forms come from `conjugate.c`, and
  the explanation shown after a wrong answer is generated from the same tables,
  so the app can never mark the correct form wrong.
* **Chess is fully legal.** Move generation is pseudo-legal plus a
  make/check/unmake filter, so a move that leaves your own king in check, an
  illegal castle or a bogus en-passant capture can never reach the board. The
  AI searches with alpha-beta behind a hard node budget (never more than 20,000
  nodes), which keeps its turn well under a second on a DSi.
* **Mini-games can't corrupt memory.** Every board access is bounds checked;
  cells above the Tetris board are legal (that is how a piece enters), and a
  rotate that would leave the board is rejected by a small kick table.
* **Streaks are per session.** libnds exposes the real-time clock only to the
  ARM7 core, so a "day" here means one play session: reach the daily goal and
  the streak grows on the next boot, miss it and it resets.

## Tests

The logic (conjugation, question building, Tetris, chess) also compiles on a PC
with AddressSanitizer and UBSan:

```sh
gcc -DHOST_TEST -Isource -Wall -Wextra -fsanitize=address,undefined \
    tools/test_logic.c tools/host_stubs.c \
    source/conjugate.c source/quiz.c source/data.c source/tetris.c \
    source/chess.c -o /tmp/logic_test && /tmp/logic_test
```

It prints the full conjugation tables (worth reading: this is the material the
game teaches), checks that the drill mask really filters the question types, and
fuzzes 30,000 questions and 400,000 Tetris frames.

For chess it runs **perft** on the standard positions, which is the accepted way
to prove a move generator is complete and legal:

| position | depth | nodes |
| --- | --- | --- |
| start | 4 | 197,281 |
| Kiwipete | 3 | 97,862 |
| position 3 (en passant) | 3 | 2,812 |
| position 4 (promotions) | 3 | 9,467 |

It also plays 150 random games (60,000 legal plies) asserting that piece codes
stay in range and both kings always exist, and checks checkmate/stalemate
detection, the four-way promotion picker and the touch-selection logic.
